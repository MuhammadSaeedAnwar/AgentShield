# AgentShield repository structure

This repo has been reorganized into a more standard layout so the package code is separated from the data, docs, config, notebooks, scripts, and tests.

Project layout:

- src/agentshield/        # Python package
- configs/                # experiment presets
- data/                   # benchmark datasets / case files
- docs/                   # documentation
- notebooks/              # analysis notebooks / scripts
- results/                # generated result outputs
- scripts/                # helper scripts
- tests/                  # test suite
- README.md               # project overview

This keeps the codebase easier to navigate and maintain while preserving the original repository content.
